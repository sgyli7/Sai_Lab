原420/10°报告的Fx20/Fz0只证明该假设下的机器人静力分配。真实车端pitch自由、杆心比枢轴高44.2803mm时，20N水平力额外产生0.885606Nm；若弹簧仅平衡自重，嘴仍须向下约20tan10°=3.52654N。不能忽略后称真实系统更省力。

|---|---:|---:|
