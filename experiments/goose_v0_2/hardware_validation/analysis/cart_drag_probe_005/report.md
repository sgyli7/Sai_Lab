# Goose嘴部Teacher/IK局部物理抓取005

## 结论

原嘴机构确实能通过纯接触夹住真实车杆。配平实验变体中，约37.3mm真实局部牵引后，双侧接触持续保持5.18s、未脱嘴；保持末相对捕获点仍滑11.2mm。不能据此宣称无滑、硬件验收通过、整机倒退、20kg运营能力或最大负载。

首先暴露的是自由拖头重力下落与Teacher姿态跟随耦合，不足以判定嘴摩擦材料或电机必须升级。原未配平车在张嘴时杆高由420mm下降到约314mm；单独弹簧配平减少初始车漂移并改善牵引，但接近后杆仍约316mm，不能宣称弹簧维持420mm。

## 物理与数值边界

20kg自由实箱600×400×150mm，惯量(.3041667,.6375,.8666667)kg·m²，真台面181.5mm、初始中心cart+[.325,0,.2565]。车7.815342443kg，车货27.815342443kg；箱平均台面支撑196.20N，相对车最大位移不足0.4mm。无物体焊接、吸附、外力搬物或在线qpos改写。静止躯干fixture明确为局部台架，原root_z=.005000002806m对齐；头颈全部真驱动。

冷态直接对准实际杆、上下嘴与杆几乎零间隙接触且目标等于实角，没有预紧目标。曾预检15mm后撤姿势发现2.60mm穿透、0步拒绝；正式5次均未采用该姿势。raw脚本中“15mm后方起步”注释是遗留错误，以cold_state为准。只在初始化写qpos。主动张嘴→IK跟踪实际杆→合嘴→请求约50mm缓慢颈短拉→保持5.18s→放开；第3负对照在无捕获判据5.54s停止。所有请求经原18轴runtime_adapter、200Hz物理/驱动、50Hz命令、slew、原扭矩-速度曲线、350W连续功率限幅，禁用峰值，beak_input_rotor真驱动和四杆约束原样。

机器人/地面/杆实际混合μ=.65，未降材料摩擦。四轮frictionloss=.125Nm对应名义8N等效阻力（R=.0625m），是显式集总轴阻力变体，不是已标定实车阻力；原始轴摩擦约束力没有单独存证，不能把8N说成逐步实测牵引。实际嘴→杆世界力逐步记录。

五场均831项原编译物理字段/原关节阻尼摩擦/网格/驱动/闭环等精确；53原文件及原订单7源哈希完全匹配。原XML未改，车弹簧仅位于raw第5场景。全场warning=0、驱动曲线和正功率上限复核通过。

数值限制必须保留：第5合嘴2.15s的beak_distal_pin最大单轴残差1.68mm，保持最大0.148mm；第5嘴杆动态最大穿透1.17mm、保持0.866mm。均使用原solver，不能把软接触仿真当无变形制造验证。其他场景逐项残差/穿透见JSON。第5pull/hold无嘴-轴/叉额外承载，保持双侧接触100%；第1/2保持末杆已接近/略越保守工作面安全边界，第5仍约26mm余量。

逐步日志中的qpos/相对姿态为积分后状态；接触力/接触距离/约束残差为该5ms步的求解值。记录真扭矩、实际输入转速、正功率、所有接触力/摩擦、真实箱/车/根姿态、闭环反力和警告。足滑/车箱支撑等离线由完整轨迹核验。单独50Hz原始请求未另存，逐200Hz实际slew目标已保存；可复现实验由每场fresh harness与场景、原适配器和cold_state确定。

## 下一步最小工作

暂不改嘴形或静默提高μ。先把被动pitch配平/限位与咬杆姿态做真实器件和静态力矩校准，再复做同Teacher抓取+配平开嘴负对照；以固定接触面余量、保持滑移和杆X力为嘴硬件改进判据。若校准后仍有明显滑移，再单因素评估工作面浅凹导向/可更换接触垫，保持轴线与原驱动不变。

用户游戏参考表达低头叼持、压低身体、用腿持续倒退。本轮只有局部嘴台架诊断，没有复现该整机动作。后续须具备受载平衡的全身Teacher/IK退步控制，原限制下自由根、无足/root绑定，先验证小幅退步和稳定传力；本轮不研发步态、不做PPO/网络训练。未执行R2、20N、free-root；局部稳定传力与数值质量尚不足以放行整机后退。
