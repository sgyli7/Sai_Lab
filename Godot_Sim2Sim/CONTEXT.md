# MicroDuck 策略部署

本项目比较机器人策略在源仿真和目标仿真中的动作，并探索可独立分发的运行版本。

## Language

**独立运行版**：用户启动即可控制 MicroDuck 的应用，所需模型和运行依赖随应用交付，不要求另行启动训练环境或控制服务。目标平台和同时运行的机器人数量由具体部署方案确定。

**九技能策略包**：覆盖站立、行走、坐下起立、捡地、左踢、右踢、前滚、轮滑和轮滑蹲起的一组策略。它指明本次部署实际使用的策略版本，而非所有历史候选。

**策略运行等价**：同一策略在不同运行方式下，对相同观测和控制历史产生符合约定误差的动作，并保留技能切换与复位语义。它与跨仿真的动作质量分别验收。

**跨仿真动作质量**：策略在目标仿真中完成动作的稳定性、方向、速度和平顺程度，相对于源仿真的表现。任务成功本身不代表动作质量已经一致。
