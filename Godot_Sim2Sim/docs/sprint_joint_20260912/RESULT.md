最终保留集为 **231/240 完整通过，零跌倒**；九条失败均为转弯后回直行时侧移超出5cm。候选为 S05 共用普通/加速 actor，普通请求 0.25、加速 0.30 m/s，直行路径前视 0.20 m。开发集 63/64，存在已知转弯退出侧移失败，禁止晋级默认版本。物理保持 Godot/Jolt、200 Hz 物理、50 Hz 决策。

训练和控制分别记录：本轮联合 PPO、成功轨迹教师约束、原生转弯退出课程均完成对照，但没有超过未训练控制基线。四个正式训练终点共 1,179,648 步，CUDA 学习；Jolt 采样仍在四个 CPU 核，不能称为 GPU 物理训练。

旧长回放的 222.48 秒跌落发生在 40 米地板边缘。四秒初始位置对照证实这是场景越界；新场内 600 秒连续转向、加速、普通速度与停止回放通过，最大水平坐标绝对值 5.207 米。最终包另做长测，旧“长期平地不稳”的表述已更正。

最终候选在读取保留种子 922000–922029 前冻结，后续不再选模型或控制；旧 920000–920029 保持封存。默认工作区模型未覆盖，其他八个包内模型沿用上一试验包。包内轮滑与工作区默认轮滑的既存差异未作覆盖。

长直行平均 **0.225613 m/s**，同包普通W为 **0.193168 m/s**，加速 **16.8%**。八类手势的配对加速倍率全部通过1.15门槛，停止和方向角门全部通过；剩余失败为左转退出2条、右转退出7条，侧移范围5.20–7.86cm。480条配对回放无运行错误。最终失败保留在 [机器记录](RESULT.json)，禁止据此再选参数。

独立包 `dist/MicroDuck-ARM64-20260912-joint-trial/` 已生成。Ubuntu24.04 aarch64容器预检证实无Python、无训练仓库、无网络路由，挂载包只读。实际导出文件十模型均含64条真实观测及随机/边界样本，自测最大绝对误差1.42e-14，小于1e-5。仍是本地CPU ONNX Runtime 1.29.0推理，无Python/TCP服务。

同一保留种子、相同初始位姿和输入程序的旧包对照为 **211/240→231/240**，双方均零跌倒，净增20个成功。新增成功29个，同时丢失9个原有成功（均为上述转弯退出侧移），所以不满足无回退要求。普通速度八组均保留至少95%，实测比旧版为100.2%–118.6%；普通长直行从0.166656升至0.193168m/s。改善没有靠降低普通速度制造。

- 同一冻结脚本的原生输入处理器验证暂停/恢复、复位、六次重载及历史清零通过；这是处理器测试，不是OS键盘操作。
