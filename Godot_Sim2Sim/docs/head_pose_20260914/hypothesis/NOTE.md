# 头颈前移能否改善前进：离线证据

2026-09-14。仅重算已有轨迹和静态运动学，没有启动训练、额外 Godot 或修改用户正在操作的维修站。

头颈组件 neck / neck_pitch / yaw_roll_motion / jaw_soft 共 0.2799274 kg，机器人不含球总质量 0.73724318 kg，占 37.97%。实际 Godot 刚体原点为显式自定义的惯性质心坐标，可对 body_states.pos 按质量求整机质心。

旧普通 S05 的同幅值请求 +0.25 / -0.25 m/s，在 3.02–4.50 秒、各 75 帧中，实际前向速度分别为 +0.1871 / -0.2278 m/s。头颈组合质心相对躯干质心的前向距离为 +48.44 / +26.93 mm。前进已有较前伸的头颈；该相关性不证明后移是后退快的原因，也不能判断进一步前移一定有效。

将这些实际关节角放入同源质量/几何的静态运动学，保持根部与其他关节不动：颈关节 -5° / -10° 可使整机质心前移约 2.55 / 5.08 mm；头俯仰 +5° / +10° 约前移 1.04 / 2.03 mm。两个关节轴符号不同，不能统一添加正向偏置。该计算没有动力学积分，不包含实际 Jolt 关节顺应性、策略补偿或落脚变化，不是速度增益预测。

建议下一项单变量因果实验：冻结质量、惯量、Jolt、腿部策略与命令，从颈姿态偏置 0 / -5° / -10° 入手。偏置平滑进入与退出，只在前進加速期间作用，保留实际关节反馈和最终执行动作记录；同开发种子对照净前速、落脚/滑移、跌倒、转向及停步，不能只看头的外观或最初几步。旧策略可能通过其他关节抵消偏置，这是需要测量的响应。必要时再单独测头俯仰，不同时改变两项。此动态试验尚未执行。

背景依据：[Atlas 步时和落脚位置调整研究](https://arxiv.org/abs/1703.00477)支持重心动态与支撑转换应协调，不能由前倾角单独推导速度。
