# 真实 Jolt 轨迹的 GPU 校正学习

基准提交 `b20a33d`。上轮 GPU 关节观测对齐后的模型在原生开发集是 127/128 加速、128/128 普通、7/7 已知回归，零倒，仍有转向失败。冻结游戏 Jolt、200/50 Hz、控制参数和普通 S05，只检验在目标引擎少量采样后能否学掉迁移失误。

## 固定实验

- 起点：上轮 `train_joint_fd/latest.pt` 的策略、价值网络及约束尺度；保留原 S05 残差结构、0.02 探索标准差和 0.2 动作增量界。
- 12 批，每批八课程 × 四个新训练复位种子，共 384 个完整回合；第 6、12 批为预先声明的检查点。前两批仅适配价值网络，后续对随机加速样本做 PPO；普通段策略冻结。
- 采样使用四核原生 Godot/Jolt，从复位连续运行完整课程，不移植冷状态，不经 Python/TCP 单步控制。学习、均值重建和似然校验使用 CUDA。此轮确有 CPU 训练数据采集，不能称为全 GPU 采样；其目的是校正真实目标引擎，不取代已有大规模 CUDA 预训练。
- 奖励、约束、教师权重沿用预训练定义。按动作后状态计算奖励，包含最终物理状态；真实跌倒时结束学习回报，排除其后轨迹和补齐位置。不得利用自动复位、物理冻结或评分豁免达标。
- 用真实轨迹逐批核对命令、上一动作、源策略均值、噪声和导出误差；数据不一致立即失败。探索轨迹由独立评分入口明确拒绝，不能用于验收。
- 模型训练全部停止后，两个固定终点各运行原样 263 条原生开发用例，比较 S05、前轮最佳和当前起点。原生质量合格才可能进入最终保留集 `928000–928049`。没有明确改善则不覆盖默认模型或包。

90 分钟工作上限，最后 20 分钟保留收尾；任务经有效工时监督器运行，四核、nice 10、有界超时，保留失败尝试。本轮实际动作与结果以账本和最终报告为准。
