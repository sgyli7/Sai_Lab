## R0：命令与朝向目标的一致性

最小回归驱动真实 `World.send → Objective.compute` 边界。请求向左转、同样一步响应下，原奖励反而更偏爱向右；旧逻辑仍以 `legacy` 保存。新增 `command_heading_v1` 在动作执行前，根据当时机身朝向与演员实际收到的相对朝向误差记录目标，下一物理状态据此评分。

两组均从冻结反馈策略出发，使用相同 61 维观测、网络、探索、课程和训练种子。每组每种子 **262,144** 个新转移，16 环境 × 256 步 × 64 更新。只比较终点模型，不通过训练奖励挑中间 checkpoint。训练读取 R0 独立 Python 源码快照，原生评测使用 R0 运行时快照；训练物理服务从仓库根目录启动，其服务器、机器人和场景 SHA 与验收快照一致且保持冻结。

## R1：持续停稳任务与因果任务状态

新增 `stop_hold_v1` 目标明确低速持续保持与及时确认，保留近零速的线性速度代价；确认后继续运行，不能提前结束或复位来规避倒滑。独立验收评分器不变。该目标与旧目标的差异有独立版本，不计作单纯观测收益。

新策略显式声明 **68 维输入**：保留旧 61 维，其中已有轮滑速度／高度状态；另加七维：

| 索引 | 含义 |
|---|---|
| 61 | 进入当前制动后的秒数，最多 6 秒 |
| 62 | 连续低速样本的持续时间，最多 2 秒 |
| 63 | 最近 0.2 秒平均速度大小 |
| 64–65 | 同窗口的前向、侧向平均速度 |
| 66–67 | 按关节树固定归属的左右轮接地状态 |

状态在每个动作前、同一仿真时间戳只更新一次，复位和离开技能时清除。它是可部署的任务状态扩展，不声称包含完整物理系统的所有隐状态。接地使用布尔接触信息，不读取未经校准的接触冲量。

R1 两组使用相同 68 维网络、初始化、critic、DOUBLE 残差计算和 `stop_hold_v1` 目标；一组屏蔽新七维 actor 输入，一组读取新七维。每组每种子先跑 **262,144** 样本。该组间比较检验任务状态的信息价值；不能将 R1 对 R0 的差异全部归因于观测，因为两者还改变了目标与参数化。

旧 ONNX 节点及 DOUBLE 常量保留，新增输入通过 Gather 截取旧 61 维供锚点使用。零增量策略已在 W1 制动、转向后制动、蹲起后制动上与原独立包得到完全相同的基础观测、动作与轨迹；非零增量的 PyTorch/ORT 数值检查也已通过。详见 [CONTRACT_PARITY.json](CONTRACT_PARITY.json)、[LEARNED_EXPORT_PARITY.json](LEARNED_EXPORT_PARITY.json)。

原生 C++ 只接受原 61 维或带正确元数据的新 68 维；Godot 与 Python 均生成完整状态。新策略在没有轨迹录制时也读取所需接地传感信息。数值不一致或缺少传感信息时明确失败，不静默退回旧模型。

## 判定与后续预算

所有候选均对比冻结反馈策略，先排除新跌倒、丢失旧成功和巡航退化，再比较主动制动通过率、停稳时间与倒滑。原两秒确认、距离与稳定门槛保持不变。一次短训练失败不能证明算法无效；有学习趋势的方向可增加样本，但追加预算与候选选择理由必须先记录。

原生独立入口的状态迁移与数值通过，只说明实现正确；只有真实物理回放改善才算质量收益。当前反馈候选会保留，试验输出不自动覆盖默认模型。

完整机器可读配置见 [PROTOCOL.json](PROTOCOL.json)。源域同键盘回放参照见 [SOURCE_REFERENCE.json](SOURCE_REFERENCE.json)：原策略在本次抽查的 MuJoCo 两种配置下同样未通过主动停稳，因此该任务包含新增闭环能力，不能全算作 MuJoCo→Jolt 的迁移损失。这里的抽查不代表完整原版技能评测。


## R2：依据实测响应限制学习关节

两个开发种子、三个真实前缀时刻、四个左腿关节的 ±0.15 rad 对照显示：刹车开始时这些方向都能引起响应；到近停／保持阶段，hip_yaw 和 ankle 的角度变化很小而力矩仍改变，hip_pitch 和 knee 则保留明显位置响应。详见 [ACTION_RESPONSE.json](ACTION_RESPONSE.json)。这不是全局系统辨识，也不代表受限关节对身体运动毫无影响。

R2 让残差和主要探索仅作用于两侧 hip_pitch／knee（动作 2、3、11、12），其余目标保持锚点输出。网络、68 维输入、stop_hold_v1 奖励、训练课程、种子 71/72/73、每次 262,144 样本均与 R1 full 相同；对照检验控制权限与探索方向的整体选择，不能拆称为只改变其中一项。为保留正态分布数值稳定性，未选关节的训练标准差仍为 1e-5；部署输出则精确保持。

该试验在看到 R2 结果前登记于 `r2_recipe.json`。R0／R1 使用其既有代码快照，不会被当前修改影响。旧 R1 checkpoint 在新默认身份掩码下输出完全相同，新增受限非零模型已通过严格导出对照。

## R3：成功教师回放与当前状态约束的配对试验

R0／R1 已显示多个旧成功用例丢失；代码审计确认既有 residual 正则只在当前 on-policy 状态惩罚未归一化增量，不显式保留旧成功时的访问分布。因此新增一组独立试验，保持先前 R0–R2 及追加训练的快照原样。

冻结反馈教师的 68D 零增量独立包，在新的训练初态 `71010000–71010015` 上运行七类主动制动，共 112 回合。只收录按原判据完整成功的 94 回合，得到 32,906 个真实动作前制动观测；包含重复刹停与蹲起后制动。这些不是开发／最终种子，也不拿来作最终验收。数据文件及来源均记录校验值，见 [TEACHER_REPLAY.json](TEACHER_REPLAY.json)。

两个组采用相同 68D 全关节演员、stop_hold_v1 目标、PPO 与冻结探索标准差 0.02：

- `online_kl`：在当前 rollout 的制动状态上计算对冻结教师的同协方差均值 KL。
- `replay_kl`：在上述成功教师访问分布上计算相同 KL。

每次辅助采样均按刹车 <1 秒、1–2 秒、≥2 秒的可用阶段均衡抽取 384 条；固定附加系数 0.02，保留原 residual 正则，没有做系数网格搜索。教师均值就是原生锚点，二者均值差恰为 delta；不通过近似导入的教师网络提供标签。

每种模式使用训练种子 71／72／73，累计 1,048,576 新样本。在第 64 更新保存并恢复，随后运行 192 更新，与前两组追加试验一样从新物理回合恢复；只把最后的 1M 终点纳入原生质量选择。每个种子的两个组并行训练，双方完成后再做正式配对回放。

R3 组间比较检验成功教师访问分布及其更广的任务覆盖，不单独拆分这两项效果。R3 对 R1 还增加了 KL 项，不能把差异全算作回放数据收益。数据／锚点不匹配、缺失阶段、非有限观测与恢复时数据变化均明确失败。采样使用已被 checkpoint 保存的 torch RNG。

完整参数及预算先登记于 `r3_recipe.json`；32 样本的训练／续训 smoke 只验证链路，不进入质量选模。
