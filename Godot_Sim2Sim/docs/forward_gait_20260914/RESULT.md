# 前进步态研究与四组 GPU 实验：未获得可用改善

2026-09-14。起点源码 `b51298157fc6e06cc427f945ff4a7ba5f98ab9b2`；会话 `results/forward_gait_20260914/`。本轮针对用户反馈“向前没有跑起来，后退反而更像跑步”开展研究与消融。

**四个新模型全部拒绝。** 支撑摆腿奖励没有带来可迁移的改善；两个 seed 在 GPU 代理中均无跌倒，到实际 Godot/Jolt 后分别有 12、10 个跌倒用例。纯速度续训也没有原生净改善。默认仍为 S05 普通行走 + a402 加速，未更新桌面维修站模型、速度、游戏物理或安装包。新的前进跑步目标仍未完成。

## 1. 测到了什么

每组使用同一批 4 个开发复位种子 `929100–929103`，8 条完整按键课程，包含起步、左右转向、交替转向、松 Shift、停步和重复加速。各组只评测预先固定的最终权重，不选中间 checkpoint。GPU 与原生分别有 160、192 条完整回放，执行错误均为 0。

|---|---:|---:|---:|---:|---:|---:|
| 当前默认 a402 / 0.30 | 未测 | — | 32 | 0 | 0.2317 | 0.2307 |
| a402 / 0.45 | 23 | 0 | 10 | 0 | 0.3317 | 0.3272 |
| 纯 tracking / seed 952410 / 0.45 | 28 | 0 | 11 | 0 | 0.3228 | 0.3103 |

“通过”指既有独立评分器的方向、转向、停止、技能选择和不跌倒门槛，本身不包含速度增益判定。0.30 默认组是稳定性基线，不冒充 0.45 目标的成功。正式推广还要求完整原生通过、长直行至少 0.35 m/s 和普通行走配对保留至少 95% 速度；新模型在第一道门已失败，未进入配对普通、最终保留种子或安装包验收。

长直行均速沿用评分器在加速稳定区间的身体前向速度；净位移均速另用 4–20 秒的躯干位置，投影到 4 秒时朝向。表内均包括跌倒回合，未删除慢速失败样本。两组支撑奖励各有一个长直行窗口内跌倒，因此其跨种子步长汇总标为无效，不能只报幸存回合的步幅。

纯 tracking 的局部方向误差有改善，但不足以抵消完整课程与速度回退。支撑奖励 seed 952410 的首次跌倒可在 4.02 秒出现；多条课程共享相同前段，因此 12 个跌倒用例不等于 12 种独立失效原因。详细重叠失败类型与时间见 `evidence/outcome_audit.json`。

[轨迹图](native_gait_comparison.png)使用预先固定的开发种子 929100，仅用于看位移、躯干俯仰和接触时序；该种子的支撑奖励直行恰好未跌倒，不能用这张单例图代替上表的全部复位结果。

## 2. 这不是 Shift 没传到模型的成绩差异

- 五组跨后端对照共 **132000 帧**：请求命令最大绝对误差 `4.996e-16`，加速技能选择错误为 0，有效控制配置相同。
- 同种子初始 actor 观测最大误差 `3.553e-15`。这不等于全部刚体、接触缓存和求解器内部状态完全等价。
- 每个原生组各抽取 512 条普通、512 条加速真实观测；共 **6144 条**实际动作对照，按 float32 比较 Python ORT 与原生记录动作，最大误差为 0。
- 六组原生十模型随机 / 边界自检通过；新训练导出与 CUDA actor 最大误差 `1.3113e-6`，小于 `1e-5`。自检 fixture 复用输入并为候选重算期望动作，不能把其 `real_count=0` 宣称为真实观测覆盖；真实覆盖来自上面的另行抽样。
- 没有自动复位、刚体冻结、后退限速或减少正常巡航来制造成绩。物理继续使用原生 Jolt，200 Hz 物理、50 Hz 决策。GPU 端是经已有标定的 Warp/MuJoCo 训练代理，不是原版 MuJoCo 策略表现的直接证明。

因此，输入接线和导出算术错误没有解释本轮差距。闭环动力学、状态表示 / 投影、训练分布和优化目标仍可能共同作用，尚未定位唯一原因。

## 3. 研究如何落实为可证伪实验

[一手来源研究](../research_forward_gait_20260914.md)审阅真实部署与开源训练方案，区分高速展示、完整操控和长期实机证据。高速运动研究强调动力学可行参考、落脚与推进协调；不能把“身体前倾”直接替换成固定姿态奖励，也不应要求所有跑步都必须出现腾空。

本轮只检验一个变量：在纯命令 tracking 基础上，是否加入固定权重 1.5 的“前进时有效单脚支撑摆腿”项。窗口借鉴 MicroDuck 上游 velocity recipe：摆动脚离地 0.125–0.300 秒；另要求对侧接触地面、实际脚底凸包最低点高于地面 5 mm、躯干倾斜小于 0.35 rad、高度大于 0.08 m，乘以截断到 `[0,1]` 的实际前速 / 请求前速。只在加速选择有效时计奖，不增加外部相位输入。

两组均启用相同的被动接触监测。每个训练 seed 各跑 off / support，总计 **4 × 8,388,608 = 33,554,432 条新 transition**。每组 512 个 CUDA 世界、64 步 rollout、256 次迭代，CUDA 物理与 CUDA PPO；从同一 a402 actor/critic 权重暖启动，重新初始化优化器和物理回合。S05 普通策略冻结，教师权重 0.02、残差幅度 0.2、探索标准差 0.02、控制、CaT 和游戏物理均相同。

学习与采样合计约 14.8 分钟；四组主监督任务含初始化、导出约 15.2 分钟。逐组精确时间、模型 SHA、设备和配置见 `RESULT.json`、`evidence/training_completed.json`。冒烟与工程验证不算正式候选，不计入上述 3355 万条实验数据。

被动监测仅识别实际激活接触约束，不测承重力或前向推进力；Warp 接触 / 几何快照相对积分后速度有一个 5 ms 子步的时差。瞬时正向速度也不能独立排除前后摇摆，因而需要独立净位移指标。未加入足底滑移惩罚或强制左右交替。这些限制意味着本次否定的是此项固定配方的实用价值，不是所有参考步态训练。

## 4. 已纠正的判断与保留的失败

1. **教师约束误判撤回。** 开始时从通用 sampler 的类别描述误以为 a402 教师包含高速指令；核验实际 replay 后，11488 条观测的 vx 范围仅 `[0,0.25]`，`vx>=0.275` 为 0。一个使用旧 replay 的 64 环境 × 5 迭代冒烟被撤回，未启动完整教师范围实验。正式四组使用同一正确 replay。生产代码只增加实际数据分布审计，没有修改教师作用范围。
2. **预注册字段残留。** 原始 `protocol.json` 的 `ablation_signal` 仍残留 withdrawn 方案的 protected/all-replay 命名。原文未改，另存 `protocol_errata.json`；不据此声称统计显著或补写事后胜出门槛。主假设、off/support 单变量、四个固定终点和 32/32 原生硬门均明确，所有候选失败，不能用此问题为任何晋级辩解。
3. **监测器检查曾失败。** 首次把独立 Warp 世界的整条轨迹要求位级一致，未通过；保留失败日志。修订检查证明同状态读取前后物理 / 控制数组不变、抬高机器人后接触消失、实际凸包高度正确；不把独立回放差异的唯一原因武断归为随机性。两训练组启用相同监测。
4. **续训工程检查。** 四组正式权重冻结后，修复暖启动续训的来源记录继承，以及无加速样本时的空统计。新建 64 环境冒烟后从第 5 次继续到第 6 次，来源保留、导出误差和空样本分支均通过。正式实验的旧源码快照独立保存，未重写其来源记录。
5. **归档检查失败后重试。** 初始冻结清单只含 135 个脚本 / 场景 / JSON；完整 suite 清单另含 27 个二进制 / 资产，直接比较字典失败。135 项没有任何内容变化，失败前没有删文件。重试逐项校验并保存完整运行时基底和各候选覆盖文件。

残差审计中，四组最后抽样 P95 约 0.138–0.144，接近上限的元素比例始终小于 0.03%；教师梯度范数相对 PPO 的中位比约 3.5–4.0%。存在局部梯度冲突，但这些观测不足以把“容量不够”或“教师压住速度”认定为主瓶颈。

## 5. 下一轮改什么，何时停止

优先检验 **原生 Jolt 数据复用 + CUDA off-policy 学习 + 缓慢策略更新**。更贴近问题的证据是 ETH / Google DeepMind 的 [2026 Sim-to-Online 实机研究](https://arxiv.org/html/2602.20220v1)：预训练策略继续学习会退化，保留数据、暖启动和较慢 actor 更新有受控消融支持。它提供设计依据，不能保证我们的 PPO actor 换成 SAC 后有效。

下一实验需完整接入数据和 critic，尚未实现或启动：

1. 同一 a402 与冻结物理，用两个受管 Jolt worker 收集真正的动作后 transition。记录 obs、动作、控制状态、reward、next state、终止 / 超时、技能和策略版本；采完即关闭，GPU 负责学习。旧教师观测不是 SAC replay。
2. 新建 SAC Q 与 target Q。a402 只有 PPO critic，不能直接继承为 Q；先冻结 actor 收集 5000 条目标环境样本，检查数值契约和新 critic，再缓慢开放 actor。跨加速到普通模式的 bootstrap 使用冻结 S05。
3. 两个训练 seed，各比较原生 PPO / replay SAC，固定每端点最多 50000 条新 transition。SAC 的首个有来源起点是每条新 transition 约一次 critic 更新、每 20 次 critic 更新一次 actor、actor LR `1e-5`。明确记录 batch 与总更新数，不把“快 SAC”的大规模 GPU 仿真时间当作少量 Jolt 数据保证。
4. 筛查要求两 seed 都有原生净改善：相对相同命令 a402 至少多过 4/32、配对长直行净速提高至少 5%，普通 / 退出不新增回退，并优于同样原生采样预算的 PPO。此门只决定是否继续投入，正式上线仍需完整无跌倒与保留集验证。若无改善，停止该固定配方，不继续扫描更新次数。

失败前短段的动作 / 状态 / 接触误差诊断仍保留；只有发现可重复误差结构才改代理。相位输入、网络扩容、参考库和短模型 rollout 分别是后续可选实验，不同时堆进下一轮。当前证据支持暂停同类代理奖励训练，不支持放弃游戏 Jolt 或宣称硬件无法跑步。
