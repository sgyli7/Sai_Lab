# Bounded command tracking after the shared-policy counterfactual

The matched 256-iteration comparison rejects the hypothesis that shared control alone fixes the task: native split119/128 versus shared91/128, both zero falls and ordinary128/128. Projected native resets fail in GPU too (113/135 versus81/135 candidate/regression cases). Shared normal long speed remains0.2046m/s in Jolt, while sprint0.2865m/s; normal acceleration dilution is not the observed blocker. GPU shared long speed0.3447m/s exceeds the requested0.30m/s while turning constraints fail50segments. More speed reward is not equivalent to successful control.

The previous task reward keeps paying6*forward speed up to0.6m/s and charges only0.5*squared yaw error during turns. Overspeed can therefore compensate for missed steering. CaT's soft termination probability does not provide a hard guarantee against that tradeoff.

[CaT Table I, option A](https://arxiv.org/html/2403.18765v1) uses bounded translation/yaw command tracking; option B formulates tracking itself as constraints. Its all-hard-constraints and boolean-termination ablations failed to learn from scratch. This does not prove they would fail with our pretrained actor, but it is evidence against treating them as an automatic fix.

Experiment: replace only the task tracking objective with Table I option A: exp(-||body-frame target velocity-actual||²/.25)+0.5exp(-(target yaw rate-actual)²/.25). Use the executed actor command including path correction. Preserve existing straight-path/heading, balance and action-smoothness costs; remove the old redundant manual-turn quadratic task cost. Keep the four CaT surrogates, probabilities, shared controller, teacher data/weight, initialS05, seed953101, 256x64x512 samples and frozen physics/control. Compare against the already frozen shared endpoint, not a selected checkpoint. Three behavioral reward tests and a bounded GPU smoke precede training. No command-range or acceptance changes. Outer speed curriculum is a possible later step, not implemented by this experiment.
