# 第二阶段：载货柔顺性，实施前协议

用户纠正：不能只纠正误抬腿或展示游戏内贴地；需要 MuJoCo 复杂凹凸地面与台阶的全面训练，尽量降低背部货物颠簸。第一阶段未合入主线，实验默认启用已撤回。

## 排序假设与因果探针

1. 固定腿 PD 80/2 让地面高频位移传递到货台。只降低支撑腿刚度应降低高频货物加速度，但可能导致静态下沉，需实测。
2. 支撑重力负荷与柔顺控制没有分离。用接触支撑力经腿 Jacobian 提供支撑，再加有限刚度/阻尼，应能在保持车身高度和通过率时降低冲击。腿关节自身 qfrc_bias 不能独自支撑浮动基座。
3. 台阶固定抬腿落脚与地形过渡冲击是剩余货物颠簸来源。先保留跨阶轨迹，独立验证支撑腿柔顺；若跨阶本身仍是瓶颈，再针对落地速度/相位连续性训练，不混改几何分类。
4. 原评估漏掉高频冲击和货物相对滑移。子步采样的自由货物轨迹应暴露50Hz空载指标遗漏的问题。

## 模型、采样、课程

- 完整 26 刚体机器人、真实关节和货台碰撞，增加独立自由物体，初始化放置在现有货台（初始化允许，运行中不写物体位姿、不焊接）。先开放货夹暴露舒适性，后续对既有夹持状态另行确认。
- 同现有100g/40x30x40mm物体，训练覆盖50/100/250g。承载机体约9.276kg。载荷是场景变量，不偷偷降低机器人质量；摩擦与求解器按基线冻结。
- 凹凸场景：二维连续随机波面、左右错相起伏、凸包、凹坑、短波搓板、纵横斜坡。台阶用真实竖直碰撞箱体，不用平滑高度场近似；20/40mm 上下连续台阶；混合地形包括起伏接阶梯与离阶恢复。
- 训练、开发、最终保留种子分离，最终保留集冻结后只评一次；不据保留结果继续拟合。
- 物理1kHz采样独立货物世界速度差分与冲量；货台参考点包含刚体角速度的杠杆项。记录原始峰值和统一带宽滤波的RMS/P95/jerk，接触力、滑移/跳离/掉货、车身姿态、悬挂行程、驱动力饱和。

## 对照与控制边界

第一阶段几何悬挂是基线。先单变量验证低刚度，然后添加支持力前馈；训练只在可行参数域内进行。新的力矩合同必须同时实现于 MuJoCo 与 Jolt，原力矩上限不变。任何训练特有可观测量不进入部署控制器。

粗糙地面保持请求0.5m/s（另外检查0.25与倒车），真实台阶保留0.12m/s技能速度；禁止优化器靠降低请求速度、提前停车、减小地形或绑定货物得分。硬门槛：任务完成、无跌倒/掉货、悬挂不过行程，平地和20/40mm原有跨阶能力不退化。舒适性按各地形类别与最差组对照，不能只报平均奖励。

若某个动作/物理模型不能通过，记录具体失败并继续定位；不能把第一阶段的51项空载通过当作载货完成。
