# Sai 连续地形悬挂与台阶分离（2026-09-15）

目标：连续地形维持请求速度、轮地接触并降低车身振动；真正台阶保留跨阶能力。用户视频约 10 秒，为科学考察站 Sai 001。视频只用于定性，不能推算真实速度或轮地接触。

## 已复现

原 MotionController：15 点 wheel_path 平缓线性爬升 0/5/10/15/20 mm，原 24 点扫描也线性上升。请求 0.5 m/s，实际送入策略变为 0.12 m/s，stage=stairs。真实调用回归断言失败。原 gate 仅检查 ptp>4mm；release targets_stairs_numpy 固定叠加 55mm 抬腿和 3.2s 周期。

## 排序假设与判定

1. 几何误分类：连续坡面只有高度跨度，没有阶跃，仍切 stairs。关闭误分类应恢复 0.5 指令，真台阶应保留。
2. 悬挂能力缺失：只修 gate 后，连续起伏仍可能失接触/颠簸；训练地形相对的有界悬挂补偿应改善这些物理指标。
3. 模拟器差异：MuJoCo 的改善可能不能迁移到 Jolt，因此必须独立 Jolt 验收。

## 选定设计（实现前冻结）

- 保留现有 flat ONNX、轮速/航向控制和 stairs ONNX/抬腿参数。
- 新增 20mm 间距近场三条纵向真实碰撞射线。用局部阶跃相对邻域坡度识别边缘，而非全域极差。原 82D 模型观测保持一致；旧客户端无新采样时兼容旧接口，连续坡面可由旧样本线性残差排除。
- 逐轮地面高度和实际车身姿态驱动腿 IK 相对补偿，限定行程、变化速度。仅电机目标控制，不修改质量、惯量、摩擦、机体位姿。
- 使用物理回合上的低维参数训练（有界优化），先验证解析初值，再训练，不从零重训全部策略。可审核的参数空间：地形补偿增益、姿态补偿增益、平滑时间常数。训练目标不奖励低速；车身振动、轮地间隙使用真实接触/地形参考。
- 分层对照：原版 / 仅正确地形分类 / 分类+悬挂。固定训练种子；冻结后使用不同地形和命令验收，不能根据留出结果反复调参。训练记录保留所有候选及淘汰原因。

## 验收门槛

- 连续坡面/波浪不触发 stairs，真实 20/40mm 边缘仍触发；不同偏航、左右轮非对称、停车、反向、蹲起均覆盖。
- 名义 0.5m/s 连续可通行地形平均前速至少请求的 80%，且不以降速提高得分；平地动作不退化。
- 相对仅修分类，悬挂候选的综合车身角振动/轮离地指标改善，且不跌倒、不增加明显抬轮。接触和间隙分别报告，不只用离地绝对高度。
- 原 20/40mm 上下台阶回归，原生 Godot/Jolt 验收；未通过不替换正式版。

边界：悬挂行程有限，大障碍、陡崖不保证滚过。密集 raycast 是当前仿真感知，不宣称真实视觉感知已实现。训练和验证副本位于项目内 sai-suspension 分支，未触碰主目录未提交工作。
