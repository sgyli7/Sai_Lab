# Sai 第二阶段：真实载货柔顺性与 MuJoCo 训练研究

日期：2026-09-15。本文响应用户进一步要求：凹凸复杂地形和台阶均需优化，车身不应僵硬，尽量降低货物扰动。第一阶段几何悬挂只是有用基线；本文未修改控制代码或启动训练。

## 判断

下一阶段应训练**接触和载荷条件下的有界主动阻抗/运动残差**，在完整 MuJoCo 机器人及独立货物接触模型中优化，而不是继续只搜索三项地形 IK 参数。基础轮速、航向和跨阶运动可作为初始化/参考；训练必须覆盖滚动、跨阶与切换，且对货台和物体直接计分。模型与 Jolt 使用相同的电机力矩公式、饱和、更新频率和滤波状态。若改变可调刚度，必须同时解决静态支撑，避免“更软”仅表现为机身塌陷。

这是根据本地结构作出的工程建议；没有一篇论文直接验证当前 Sai 的实现，也没有证据支持未经试验就宣布“最稳”参数。

## 源码审计：真正缺少什么

1. [第一阶段 Suspension](../../src/sim2sim/sai_suspension.py) 只改变 hip/knee 的目标角度，三个参数是地面增益、姿态增益、滤波常数；按四轮平均高度去除公共模态，且 `stage == stairs` 时完全禁用。它没有改变电机刚度、阻尼、载荷支撑或台阶落轮冲击。
2. 上游固定版本的 [CPU torque_numpy](https://github.com/sgyli7/Sai_Agent_001/blob/5d2ab070dcdbae61a8d750a3f812e77ad2568f26/src/sai_agent/control.py) 与 [Godot apply_command](https://github.com/sgyli7/Sai_Agent_001/blob/5d2ab070dcdbae61a8d750a3f812e77ad2568f26/integrations/godot/robot.gd) 的腿主动电机均为 `clip(80*(q_ref-q)-2*qdot, -8, 8)`；轮速环为 `clip(0.4*(omega_ref-omega), -1.3, 1.3)`。Godot 另施加 `-0.03*qdot`，对应 MuJoCo 模型被动关节阻尼；不能把这一项重复加进 CPU 电机，又保留 XML damping。
3. [JointAdapter](https://github.com/sgyli7/Sai_Agent_001/blob/5d2ab070dcdbae61a8d750a3f812e77ad2568f26/src/sai_agent/runtime.py) 只有机械臂使用 `qfrc_bias`；腿靠位置误差产生支撑力矩。其 cargo_drive 静止保持律也不同于实际 [CargoTask](https://github.com/sgyli7/Sai_Agent_001/blob/5d2ab070dcdbae61a8d750a3f812e77ad2568f26/src/sai_agent/cargo_task.py) 的夹持伺服。不能把普通 locomotion adapter 当成完整载货执行器合同。
4. 实际完整 `models/full/robot.xml`（固定包及本机 RobotDesign 同名文件均核验）包含 **26 个机器人刚体＋1 个独立物体**，总质量约 9.375759 kg，其中货物 0.1 kg、尺寸 40×30×40 mm。货台主要碰撞几何刚性附属 chassis；两块夹持滑台是独立滑动关节，行程 67 mm，cargo_drive 上限 0.12 Nm。不能把滑台误当竖向悬挂。
5. MuJoCo 夹持皮带是两条 joint equality，Godot 是每支 `20000 N/m + 4 Ns/m` 的力级弹性近似；货物本身无焊接约束。上游规格明确 0.12 Nm 是仿真暂定值，皮带/接触尚未标定。这个差异会直接影响货物振动，必须记录并独立验收，不能承诺完全等价。[模型及规格](https://github.com/sgyli7/Sai_Agent_001/tree/5d2ab070dcdbae61a8d750a3f812e77ad2568f26/models/full)
6. [第一阶段实验脚本](../../scripts/sai_suspension_experiment.py) 使用 `locomotion-articulated.xml`，只用 50 Hz 的机身局部 `v_z` 差分估算“竖向加速度”。该量会受机身坐标旋转影响，不是世界竖直加速度，也不是后部货台或独立物体的加速度。因此旧指标的改善不能直接作为载货舒适度证据。

## 一手研究：可借鉴原则与不能外推之处

- **Hogan 阻抗控制**：运动位置本身不足以描述接触交互，还应控制力与位移/速度间关系。对 Sai 的含义是必须触及真实电机力矩反馈，而非仅把目标轨迹滤得更平滑。文献是一般机器人交互理论，不提供 Sai 参数。[作者 MIT 原文](https://newmanlab.mit.edu/wp-content/uploads/2017/06/1984-impedance-control-of-industrial-robots.pdf)
- **VICES（2019）**：研究任务空间可变阻抗动作空间，实验为接触操作任务；支持把学习动作限制为有物理意义的柔顺参数，但不能外推其性能数字到轮腿行驶。[论文](https://arxiv.org/abs/1906.08880)
- **Impedance Matching（2024）**：用扫频比较仿真/真实关节闭环幅频响应，在训练前识别执行器参数并限定随机化范围。其论文部分分析忽略相位；Sai 的 MuJoCo/Jolt 迁移仍应检查相位/延迟，因为这是悬挂关键。实验是 Mini Cheetah，不应照搬其增益。[论文 III](https://arxiv.org/html/2404.15096v2)
- **HAC-LOCO（2025）**：作者指出只追求鲁棒可能形成僵硬、高频动作，分阶段学习外力估计与顺应模块。它通过调整速度命令实现对人类/外力的让步，不是货台减振；不能把降速当作本项目主要成功条件。[论文](https://arxiv.org/html/2507.02447v1)
- **Racing a Wheeled Quadruped（2026 预印本）**：轮腿四足通过腿产生侧倾力矩，RL 目标含轮地接触、力矩/功率、动作变化，研究重点为转弯载荷转移。说明货物扰动不能只看竖向，转弯横向加速度也需纳入；不能把赛道结果当货运验证。[论文](https://arxiv.org/html/2606.26313v1)
- **Rudin 等地形课程（2021/2022）**与 **Arm-Constrained Curriculum（2024）** 分别为大规模地形课程、轮腿机械臂耦合提供参考。Sai 应显式把负载与机械臂惯性纳入课程，但本文不要求迁移到论文使用的引擎或完全重写机器人。[地形课程](https://arxiv.org/abs/2109.11978)、[轮腿机械臂课程](https://arxiv.org/abs/2403.16535)

## 建议的控制合同

首个可训练版本建议保留位置参考骨架，在**物理子步**执行下式，策略/参考以 50 Hz 更新：

`tau_motor = clip(tau_support + Kp*(q_ref-q) + Kd*(qd_ref-qdot) + tau_residual, -8, 8)`

轮关节单独保留现有 ±1.3 Nm 轮速反馈，手臂和 cargo 分支另列合同。先选一种动作表达（有界姿态/腿长残差＋有界阻抗调节，或有界力矩残差），避免同时开放许多互相抵消的自由度。`qd_ref` 若采用零，训练和部署均为零；若由目标差分产生，必须统一滤波与限速，并验证切换时的微分冲击。Kp/Kd 取正、有上限，变化率受限；正增益本身不保证时变阻抗被动或稳定，仍需闭环扰动检查。

CPU 输出写入命名关节 actuator；Godot 将同一标量力矩沿同一关节轴施加于子体，并对父体施加等大反向力矩。被动摩擦/阻尼单独列出，夹紧与被动力矩的先后顺序必须一致。不使用 `gravcomp`、外加悬浮力、冻结姿态、提高摩擦或增大电机上限让结果变好。

### 支撑补偿不能误写为“全身重力补偿”

MuJoCo `qfrc_bias` 是重力、科氏和离心项之和。对 floating-base 模型，腿关节的 bias 分量主要反映相关下游肢体的动力学；它不自动代表经轮地接触传递的整机/货物支撑需求。不能直接给浮动基座施加补偿力，也不能复制 `qfrc_constraint` 作为部署可用真值。[MuJoCo 动力学定义](https://mujoco.readthedocs.io/en/stable/computation/)

两种可审查选择：

1. 初期用真实站立接触平衡状态获得与姿态/蹲姿相关的支撑力矩参考，并只在有支撑的阶段使用；说明它不是适用于任意坡面/负载的解析全身控制。每个验证负载不得重新拟合。
2. 显式解接触力分配：期望支撑合力与合力矩→每个支撑轮的法向/切向力→腿 Jacobian 转置力矩，再叠加适当关节 bias。解要约束非负法向力、摩擦锥、实际支撑状态和电机饱和；坐标/正负号必须以“是否正确承重”测试确认。不要把地面反作用力和足端对地作用力符号混用。

具体地，若 F 定义为地面对机器人的反力，`M*qdd + bias = S^T*tau + J^T*F`，静态关节支撑项是 `bias_actuated - (J^T*F)_actuated`。分配还要匹配负载位置引起的 roll/pitch 力矩，不应默认四腿均分 mg。模型中的独立物体若仍留在地面，不应被算作已承载质量；用实际承载状态区分。失联/摆动轮卸载要平滑，不能通过无接触轮施加虚构地面支撑。

仅降低 Kp/Kd 没有支撑前馈可能增加静态偏差或到底；增加 Kd 过多也会把地面速度直接传给机身。选值应由承重、扫频和扰动响应界定，不使用“越软越好”的假设。导纳方案需要可靠外力估计和额外积分状态；当前跨引擎力信号未对齐，第一版优先直接力矩阻抗，避免未经验证的力导纳外环。

## MuJoCo 训练组织

先完成合同/承重探针，再进行实际动力学训练。完整模型包括货物、夹持、机械臂、所有质量与碰撞；GPU 精简 locomotion 环境若缺少货物动态，不可直接用它的奖励声称完成载货训练。可用 CPU 向量环境训练较小 PPO 残差，也可先做有界阻抗参数优化建立可信初始化；二者必须分别报告，不把参数搜索写成 PPO。

建议逐步课程但始终混合回放：

1. 平地加载、起停、蹲立，低幅凹凸纵横起伏；先学保持载荷且不过度僵硬。
2. 同轮/错相凸包、凹坑、长坡、短波纹、斜穿和坡顶/坡底，提升幅值、曲率与速度；地形类别比例预先固定。
3. 独立台阶上/下、连续阶梯、坡后接阶、阶后接坑和斜向接近；跨阶参考保留必要离地，支撑腿学柔顺，落轮窗口抑制冲击。不能把“台阶时关闭悬挂”作为最终方案。
4. 有界负载质量、位置、摩擦和执行器延迟随机化，作为预先声明的扰动，不改变基准工况来美化分数。先固定 100 g 标准货物，再扩展负载范围；不应宣称尚无机械额定证据支持的载荷能力。

50/100/250 g 的自由货物可作为减振敏感探针与负载变化训练范围，但它们不是原有 Sai 001 夹持流程的替代品。最后至少包含原装 100 g 物体、原夹持皮带/滑台、相同力矩上限的完整回归；自由货物与夹持货物的结论分开报告。

actor 只用目标部署可获得的姿态/速度/关节历史、地形射线、可用接触状态、模式和夹持状态；精确接触力、载荷质量真值、物体状态可先给 critic/奖励。若把物体状态交给 actor，就必须一并实现部署观测并注明依赖仿真真值。分开训练、验证和最终保留种子；冻结预算、失败门槛、最差地形组选择规则，保留全部失败候选。

## 奖励与测量：直接回答“货物是否更安稳”

**硬门优先**：货物不脱出、不翻覆，机械夹持不失效，机器人不跌倒、不长期停滞，电机/关节/行程合法；平地与真台阶保持通过率。对转弯、起停与台阶允许物理需要的速度变化，但对连续起伏用相同命令和路线比较，必须同时报告实际速度与到达时间。

**舒适度目标**：货台参考点三轴惯性加速度 RMS/P95/最大值、角加速度，独立物体相对货台的位移/姿态/速度，脱离货台时间、夹持接触保持、货物碰撞冲量、固定带宽 jerk。机身姿态、wheel contact、功率与动作平滑是辅助约束；不要把腿速度越小当核心奖励，也不要把台阶摆动轮合理离地当失败。

货台位于底盘后方。刚体点加速度为 `a_deck = a_base + alpha × r + omega × (omega × r)`（全部同一世界坐标；r 从底盘参考点指向货台）。因此底盘原点平稳仍可能使货台显著振动。直接以该点/独立物体速度差分也可，但需要统一实际采样时刻与滤波。区分惯性加速度和加速度计 specific force；如使用后者须正确处理重力，静止平台应得到预先声明的零扰动基线。

冲击在物理子步采集：MuJoCo `mj_contactForce` 是接触坐标的力/力矩，应乘子步 dt 再在相同物理事件窗口内积分；Godot `get_contact_impulse` 是冲量而非力，先核验后端支持、非零和方向，再按同窗口累加。两者用统一时间窗和接触对象分类，避免对比不可比的单步峰值。[MuJoCo API](https://mujoco.readthedocs.io/en/stable/APIreference/APIfunctions.html#mj-contactforce)、[Godot API](https://docs.godotengine.org/en/stable/classes/class_physicsdirectbodystate3d.html)

jerk 对噪声/数值差分敏感：冻结相同低通带宽、采样频率、起始暖机与统计窗口；同时保存未滤波冲量和原始速度，不能用更重滤波掩盖冲击。优化全三轴扰动，并报告最差单类地形，不能只用一条长平路稀释短台阶冲击。

## 训练前可区分原因的探针

| 探针 | 区分什么 | 应冻结的观测 |
|---|---|---|
| 单关节低幅扫频，CPU/Jolt 同参考 | 电机合同/时延问题还是策略问题 | 实际角度、主动/被动力矩、幅相响应、饱和占比 |
| 空载/100 g、不同蹲姿静止承重 | 降刚度后是否只靠塌陷补支撑 | 高度误差、稳态腿力矩、接触分配、剩余行程 |
| 单轮凸包、两同轴轮凸包、四轮同升 | 差动补偿有效还是公共模态僵硬 | 货台垂向/角加速度、前后载荷、关节行程 |
| 等总高差的长坡与短波纹 | 几何幅度与激励频率是否混淆 | 同速货台振动、相位滞后、轮接触率 |
| 单阶落轮后停稳 | 摆动动作必要性与落轮柔顺性 | 落轮冲量、货物相对位移、稳定时间 |
| 固定货台运动＋实际夹持物体 | 皮带/货物接触是否主导振动 | 夹持力、皮带误差、物体响应；只用作识别探针 |
| 载货转弯和急停 | 横向载荷转移/角运动是否漏掉 | 三轴货台加速度、左右接触负荷、物体滑移 |

最终对照至少含：原控制器、仅探测修复、第一阶段 IK、固定阻抗基线、训练候选；同一物理模型/地形/命令/负载。训练候选须在 MuJoCo 和 Jolt 独立跑完。夹持留存通过但货台加速度没有改善，不能称为减振完成；空载改善但载货/台阶退化也不通过。不得在最终保留集上继续调参后仍称其“未见过的测试集”。
